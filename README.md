# SchematIaC issues

Public issue tracker for [SchematIaC](https://schematiac.com). Install from
the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=schematiac.schematiac).
Docs: [docs.schematiac.com](https://docs.schematiac.com).

The product source is private. File bugs, parse failures, and feature
requests here. Do not paste customer Terraform or Bicep — a public sample
or a stripped-down snippet is enough.
